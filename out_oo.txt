usage: cis_overlap.exe [optional arguments] path1 path2

Calculate overlaps between two sets CIS type wave functions.

positional arguments:
  path1                       directory containing calculation for bra states      
  path2                       directory containing calculation for ket states      

optional arguments:
  -h, --help                  show this help message and exit                      
  -in, --input-format         format of input files                                
                                default: cp2k
  -in1, --input-format-1      format of input files for bra orbitals/states        
                                default: cp2k
  -in2, --input-format-2      format of input files for ket orbitals/states        
                                default: cp2k
  -ao, --ao-stop              stop program after AO overlap calculation            
  -mo, --mo-stop              stop program after MO overlap calculation            
  -alg, --algorithm ALG       algorithm to use for the overlap calculation         
                              Available options:                                   
                                CIS (very slow, not recommended)                   
                                L2M                                                
                                NTO                                                
                                default: NTO 
  -dys, --dyson               calculate Dyson orbitals instead of overlaps         
                                default: F
  -t, --wf-threshold t        truncate wave functions using given threshold        
  -tnex, --truncate-nex n     truncate wave functions to n dominant excitations    
  -ns, --(no-)norm-states     renormalize input states before calculation          
                                default: T
  -os, --(no-)orth-states     reorthogonalize input states before calculation      
                                default: F
  -oo, --(no-)orth-overlap    orthogonalize overlap matrix                         
                                default: F
  -mp, --(no-)match-phase     match phase between assigned bra/ket states          
                                default: F
  -op, --operator op          operator whose expectation values are cacluclated.   
                              Currently, only overlaps can be calculated for wave  
                              functions.                                           
                              Available options:                                   
                                analytic expression (eg. "x * y^2 - z^2")          
                                  note: use quotation marks                        
                                  note: see read_operator_string subroutine docs   
                                overlap                                            
                                r^2 (equivalent to "x^2 + y^2 + z^2")              
                                default: overlap
  -aoc, --recenter-ao         geometry at which to place centers for atomic orbital
                              basis functions in the integral calculation:         
                              (untested, not recommended to change)                
                              Available options:                                   
                                -1 - place all AOs on first geometry               
                                 0 - place all AOs at their actual positions       
                                 1 - place all AOs on second geometry              
                                default: 0
  -fmn, --freeze-mo-norm t    freeze occupied ket MOs when their norm in bra basis 
                              is smaller than given threshold. Same number of bra  
                              MOs with smallest norms in ket basis is also frozen. 
                              Used when geometry of a small part of a system is    
                              significantly different between bra and ket states.  
                              (untested, not recommended)                          
                                default: F
  -sao, --sao-output file     output final ao overlap matrix to file               
                                default: None
  -smo, --smo-output file     output final mo overlap matrix to file               
                                default: None
  -swf, --swf-output file     output final wf overlap matrix to file               
                                default: s_wf
  -p, --print-level p         control output level of program (0 = quiet)          
                                default: 2
